## Featured projects

### [CardiacSegDiffusion](https://github.com/halima-fouadi/CardiacSegDiffusion)

A research project exploring controllable diffusion pipelines to support transformer-based cardiac MRI segmentation.

- LoRA fine-tuning for segmentation label generation.
- ControlNet image synthesis conditioned on segmentation maps.
- SegFormer for downstream segmentation.
- Based on Stable Diffusion v1.5.

**Availability:** the repository currently provides a research overview for peer review. The full implementation, trained models, and dataset are announced for release upon paper acceptance.

### [Clinical evaluation of synthetic breast ultrasound](https://github.com/halima-fouadi/clinical-validation-us)

A Streamlit application designed for radiologists to evaluate synthetic breast ultrasound images alongside segmentation masks and descriptive metadata.

- Structured scoring across eight evaluation criteria, with comments and an overall assessment.
- Case navigation and resumption of reviewer progress.
- CSV and Excel exports, with Google Drive backup integration.

**Technologies:** Python, Streamlit, pandas, Pillow, Google Drive API.
